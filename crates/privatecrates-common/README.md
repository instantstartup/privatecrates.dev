# privatecrates-common

Types and rules shared by the [PrivateCrates](https://privatecrates.dev) credential provider
([`cargo-credential-privatecrates`](https://crates.io/crates/cargo-credential-privatecrates)), the storage verifier
([`privatecrates-verify`](https://crates.io/crates/privatecrates-verify)) and the server: index paths and lines,
crate-name rules, publish audiences and the storage repository layout.

It is published so that those tools can be installed from crates.io; it has no stability guarantees of its own.
